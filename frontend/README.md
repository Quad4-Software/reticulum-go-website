# Reticulum-Go website frontend

SvelteKit app for the Reticulum-Go documentation site, WASM examples, and tools UI.

Setup, Make targets, CI, and docs workflows are documented in the repository [README](../README.md).

From the repository root:

```sh
make install
make dev
```

From this directory:

```sh
pnpm install
pnpm dev
pnpm run check
pnpm test
```
